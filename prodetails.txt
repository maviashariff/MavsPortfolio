1️⃣ Stress Analyzer – Full Stack Web App

Live: https://lnkd.in/g8s38XAe

Backend Repo: github.com/maviashariff

📌 Overview

A full-stack web application that analyzes user inputs, calculates a stress score, categorizes stress levels, and presents results in a light, sarcastic tone. Built primarily to understand real-world full-stack architecture and deployment workflows.

⚙️ Tech Stack

Frontend: HTML, Tailwind CSS, JavaScript

Backend: Node.js, Express.js

Database: MongoDB Atlas

Authentication: JWT (Admin login)

Deployment: Render (Backend), Netlify (Frontend)

🔐 Key Features

Dynamic stress score calculation logic

RESTful API architecture

JWT-based admin authentication

Protected admin dashboard

Leaderboard & submission management

Secure MongoDB Atlas integration

Environment variable handling

CORS configuration & production debugging

🧠 What I Focused On

Designing clean API routes

Authentication flow (token generation & validation)

Database security best practices

Deployment pipeline setup

Debugging real production issues

💡 Why This Project Matters

This project strengthened my understanding of full-stack data flow, backend security, and cloud deployment — not just UI development.
